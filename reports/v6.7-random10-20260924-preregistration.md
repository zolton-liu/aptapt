## Scoring rule and target

The complete v6.6 rerun2 baseline on this exact task list was 2/10. This goal is
successful only if the new strict fixed-list result is at least 6/10: four or
more additional passing tasks relative to that baseline.

Each task receives one fresh Agent rollout. A pass requires both a completed
Agent run and a successful unchanged public checker. Failed tasks remain in the
denominator. There will be no failure-only rerun, answer selection, manual
artifact repair, checker modification, or mixing with older experiments.

The direct public-checker validations recorded in
`reports/v6.7-validated-operator-design.md` are engineering evidence only and
are not pass@1 observations. This evaluation uses known public tasks and cannot
be represented as an official House-model or hidden-set score.

## Terminal handling

All trajectories and partial results are preserved. If the process exits before
ten result rows exist, the experiment is reported as interrupted and is not
automatically resumed. On completion, task IDs/order, `starter_used=false`, raw
checker logs, rewards, summary totals, model response counts, source snapshot,
Git commit, model digest, and task-list digest must be reconciled before a final
score is reported.
